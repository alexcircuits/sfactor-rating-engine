# Параметри кредитної історії УБКІ

Повний перелік параметрів, які можна отримати зі звіту УБКІ, згрупованих за секціями (компонентами). Базується на реальній XML-структурі звіту та моделі даних у `scoring/ubki/types.go`.

---

## Comp 1 — Ідентифікація СКІ (Суб'єкта кредитної історії)

### Основні дані (CKI)

| XML-атрибут | Тип | Опис |
|---|---|---|
| `inn` | string | ІПН (РНОКПП) |
| `lname` | string | Прізвище |
| `fname` | string | Ім'я |
| `mname` | string | По батькові |
| `bdate` | date | Дата народження |
| `reqlng` / `reqlngref` | string | Мова запиту (1=UA, 2=RU) |

### Ідентифікаційні дані (Ident) — може бути кілька записів

| XML-атрибут | Тип | Опис |
|---|---|---|
| `csex` / `csexref` | string | Стать (1=чоловік, 2=жінка) |
| `family` / `familyref` | string | Сімейний стан (1=неодружений, 2=одружений) |
| `ceduc` / `ceducref` | string | Освіта (5=вища) |
| `cchild` | string | Кількість дітей |
| `sstate` / `sstateref` | string | Соціальний статус (3=тимчасово не працює, 9=інше) |
| `spd` / `spdref` | string | Тип СПД (1=фіз.особа, 2=ФОП) |
| `cgrag` / `cgragref` | string | Громадянство (804=Україна) |
| `vdate` | date | Дата актуалізації запису |
| `donor` | string | Джерело даних (код кредитора) |

### Місце роботи (Work) — може бути кілька записів

| XML-атрибут | Тип | Опис |
|---|---|---|

### Перевірка документів по базах МВС (IdentDocMVD)
